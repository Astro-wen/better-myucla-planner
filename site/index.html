Better MyUCLA

Drag your classes wherever you want them in the Class Planner, instead of clicking that little arrow one position at a time. 在 Class Planner 里直接把课拖到你想要的位置，不用再一格一格地点那个小箭头。

Not made by, endorsed by, or affiliated with UCLA 非 UCLA 官方产品，与 UCLA 无关联

What the buttons do 这些按钮都是干什么的

  • MyUCLA's own arrows. We left these alone, so if you just want to nudge a class up or down one spot, they work the way you're already used to. MyUCLA 自带的上下箭头。这两个我们没动过，所以你要是只想把某门课往上或往下挪一位，还是照原来的方式点就行。
  • Drag it there yourself. Grab this handle and drop the class wherever you want it in the list. If the spot you're aiming for is off screen, drag toward the top or bottom edge of the window and the page will scroll along with you. 直接拖过去。按住这个把手，就能把课拖到列表里的任何位置。如果你想放的位置在屏幕外面，把它拖到窗口的上边缘或下边缘停着，页面会自己跟着滚过去。
  • Send it to the top. Moves the class straight to first place, however far down it currently sits. 一键置顶。把这门课直接挪到第一位，不管它现在排在多靠后。
  • Move it to a specific place in the order. The number shows where this class currently sits in your plan. Open it, pick the position you want the class to end up in, and it goes straight there, so getting from 13th to 2nd is one choice rather than eleven clicks and eleven page reloads. 移动到指定的顺序位置。这个数字是这门课现在排第几。点开它，选你想让它排到第几位，它就直接过去了。比如从第 13 位挪到第 2 位，选一下就好，不用点十一次箭头、等十一次页面刷新。
  • Leave yourself a note. A short line on the class for whatever you need to remember, like that it clashes with your lab, or that you're only taking it if something else falls through. It's saved on your own computer and never sent anywhere. 给自己留个备注。在这门课上写一句话，记点你需要记住的东西，比如「和实验课撞了」，或者「另一门选不上再考虑它」。内容只存在你自己电脑上，不会发到任何地方去。
  • Fold the class up. Hides the section table underneath so more of your plan fits on screen. The seat status stays visible on the title line. 把这门课折起来。把下面那张 section 表格收掉，这样一屏能看到更多课。折起来之后，名额状态还是会留在标题那一行。

Nothing reaches MyUCLA until you press Save 在你点保存之前，MyUCLA 那边什么都不会变

You can rearrange things as many times as you like without paying for any of it, because until you save it's all just happening in your own browser. A bar at the bottom of the window keeps track of how many classes you've moved and roughly how long saving will take, and when you press Save it goes and clicks MyUCLA's own arrows for you, one position at a time. 在点保存之前，这些都只发生在你自己的浏览器里，所以你可以反复调整，怎么排都不用付出代价。窗口底部那条会告诉你已经动了几门课、保存大概要花多久，等你点了保存，它才会替你去点 MyUCLA 自己的那些箭头，一格一格地帮你点完。

Install it 怎么安装

It takes about two minutes, and it works in Chrome or in anything built on Chrome. 大概两分钟就好，Chrome 或者任何基于 Chrome 的浏览器都可以。

Download the latest version 下载最新版

  1. Unzip it somewhere you won't clean out later, like Documents rather than Downloads. Chrome reads the extension out of this folder every time it starts up, so if the folder disappears the extension goes with it. 解压到一个你以后不会顺手清理掉的地方，比如放在文稿里而不是下载里。Chrome 每次启动都要从这个文件夹里读，所以文件夹一旦没了，扩展也就跟着没了。

  2. Open a new tab, type chrome://extensions into the address bar and press Enter. 新开一个标签页，在地址栏里输入 chrome://extensions 然后回车。

  3. Turn on Developer mode using the switch in the top right corner. 点右上角那个开关，打开开发者模式。

  4. Three buttons will appear on the left, and the one you want is Load unpacked. 左上角会冒出三个按钮，你要点的是 Load unpacked（加载已解压的扩展程序）。

  5. Go into the folder you just unzipped, select the folder called dist inside it, and confirm. Make sure you're selecting that folder itself rather than opening it and picking the files inside. 进到你刚解压出来的文件夹，选中里面那个叫 dist 的文件夹，然后确认。注意是选中这个文件夹本身，别进去选里面的文件。

  6. If it worked, you should see it sitting there like this. 装成功的话，你应该会看到它像这样出现在列表里。

  7. Now open your Class Planner at be.my.ucla.edu/ClassPlanner/ClassPlan.aspx, sign in the way you normally do, and scroll down to the blue Class Plan bar. Every class should have the new buttons on it. 然后打开你的 Class Planner be.my.ucla.edu/ClassPlanner/ClassPlan.aspx，照常登录，往下翻到蓝色的 Class Plan 那一栏，这时候每门课上应该都有新按钮了。

Two things worth knowing.有两件事想先跟你说一下。

Chrome will warn you about developer-mode extensions every time it starts up. That's just its standard notice for anything that didn't come from its store, so nothing has gone wrong and you can dismiss it. Chrome 每次启动都会跳出来提醒你「请停用开发者模式扩展程序」。这只是它对所有非商店来源扩展的例行提示，不代表出了什么问题，关掉就行。

It won't update itself, so when a new version comes out you'll want to unzip it over the same folder and then hit the reload button on its card in chrome://extensions. If you unzip it somewhere else instead, Chrome treats it as a different extension and your notes and settings won't come with it. 它不会自动更新，所以出了新版本，记得解压覆盖到同一个文件夹，再去 chrome://extensions 点那张卡片上的刷新按钮。要是解压到了别的地方，Chrome 会把它当成另一个扩展，你之前的备注和设置就跟不过来了。

If you want to turn it off 不想要了怎么关

Click the extension's icon in your toolbar and flip the switch at the top. The Class Planner goes back to exactly the way MyUCLA made it, straight away, without even a reload. 点一下工具栏上的扩展图标，把最上面那个开关关掉，Class Planner 立刻就变回 MyUCLA 原本的样子，连刷新都不用。

The other switch is optional, and worth explaining: MyUCLA only counts clicks as proof that you're still there, so if you spend fifteen minutes reading your plan without clicking anything it signs you out. Turn this on and scrolling counts too. 另一个开关是可选的，顺便解释一下它是干嘛的：MyUCLA 只把点击当成「人还在」，所以你要是盯着计划看了十五分钟却没点任何东西，它就把你登出了。打开这个开关之后，滚动页面也算数。

What it can and can't touch 它能碰什么，不能碰什么

  • It only runs on one page, be.my.ucla.edu/ClassPlanner/ClassPlan.aspx, and nowhere else on MyUCLA. 它只在一个页面上运行，就是 be.my.ucla.edu/ClassPlanner/ClassPlan.aspx，MyUCLA 的其他页面它都碰不到。
  • It asks for one permission, local storage, which is where your notes and your folded-up classes are kept. 它只申请了一个权限，本地存储，用来记住你的备注和哪些课被你折起来了。
  • There's no server and no account behind it, so nothing ever leaves your browser. 它背后没有服务器也没有账号，所以不会有任何东西离开你的浏览器。
  • It never enrolls, drops, waitlists, or watches for open seats, and it never reads your password, cookies, UID, grades, or DARS. 它不会替你选课、退课或者加候补，也不会盯着有没有空位，更不会去读你的密码、Cookie、UID、成绩或者 DARS。
  • All the code is public on 所有代码都公开在 GitHub if you'd rather check any of that yourself. 上，上面这些你都可以自己去核对。

Help make it better 一起把它做好

This is still an early version, and MyUCLA can change its own pages whenever it likes. When that happens the extension stops instead of guessing, so the worst case should be that it quietly does nothing rather than moving the wrong class. 这还是个很早期的版本，而 MyUCLA 想什么时候改自己的页面就什么时候改。真改了的话，它会直接停下来而不是瞎猜，所以最坏的情况是它安静地不干活，而不是把你的课挪错地方。
